# Task-8
Superstore Sales Analysis – Power BI Dashboard     


A Power BI project analyzing Superstore sales data to gain insights into profit, sales trends, product categories, and regional performance.

Dataset

Includes Order ID, Date, Category, Sales, Profit, Quantity, and Region.

Features

Interactive dashboards and charts for sales and profit analysis.

Insights on top categories, regional performance, and trends over time.

Helps in business decision-making and reporting.


Tools

Power BI for visualization and analysis.
